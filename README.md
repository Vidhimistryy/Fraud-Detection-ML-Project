# Fraud Detection and Cybersecurity Monitoring

An educational financial-risk analytics project that compares **Random Forest** and **XGBoost** models for detecting fraudulent credit-card transactions and communicates results through Power BI-ready analysis.

## Analytical objective

The project explores how transaction features, class imbalance, model evaluation, and visualization can support fraud-monitoring decisions. It is designed as a transparent portfolio artifact rather than a production payment-fraud service.

## Workflow

The notebook covers dataset preparation, missing-value checks, train/test separation, feature scaling, model training, fraud classification, performance evaluation, visual analysis, and dashboard-oriented reporting.

## Data provenance

The original README identifies the public [Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud). Users should obtain the dataset directly from its source and verify its current license and terms before reuse. Raw or restricted data should not be committed to this repository.

## Responsible financial communication

Fraud labels are highly imbalanced, so accuracy alone is insufficient. Review precision, recall, F1 score, confusion matrices, threshold choices, calibration, and operational costs. This project is not investment advice, does not make credit decisions, and does not guarantee fraud prevention.
